# c-higt-level
Приобрести компетенции инженерного уровня с целью создания промышленного предприятия в сфере инновационных технологий в Африке — и в частности в Камеруне.
После освоения C++ и других языков программирования, о которых я расскажу в ближайшее время, моя главная цель — научиться создавать системы управления для промышленных станков, перерабатывающих сырьё, будь то сельскохозяйственная продукция, металл, алюминий и т. д.

Мы начнём с разработки простого программного обеспечения, которое позволит автоматически управлять процессом шелушения семян на всех этапах — от их загрузки до упаковки для дальнейшей реализации или потребления.
